AUM Mini Project Proposal 6th Semester

Project Sway

An intelligent LLM gateway designed to optimize enterprise AI compute workloads through semantic caching and dynamic cascade routing.

Computer Science and Engineering Department, AUM [cite: 1, 5, 8, 11]

The Architecture

1. Semantic Caching

Vectorizing inputs to serve cached responses for semantically identical queries. 0 compute, 0 API cost.

2. Intelligent Routing

Dynamically directing simple tasks to lightweight models and complex reasoning to heavy models, minimizing token waste.

3. Agentic Chunking

Deconstructing complex requests into deterministic, multi-step pipelines to eliminate hallucination and guarantee structural perfection.
