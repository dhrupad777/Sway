Roadmap

The complete technical progression for building the Sway Project. A phase-by-phase breakdown of concepts to master, datasets to curate, and models to train.

Phase 01

The Gateway Core

01 Things To Learn

  • Node.js Interception via http-proxy-middleware
  • Man-In-The-Middle (MITM) architecture principles
  • HTTP Header injection & OpenAI/Anthropic API specs

02 Things To Build

  • Initialize express.js server exposing /v1/chat/completions
  • Implement local routing logic (intercept and forward)
  • Handle Base_URL configuration for AI IDEs (Cursor, Windsurf)

03 Data & Resources

  • Collect sample OpenAI client requests & JSON payloads for validation
  • Secure credential structures for Local BYOK environment
Phase 02

Semantic Caching (Zero Cost)

01 Things To Learn

  • Vector Embeddings (text-to-vector high dimensional mathematics)
  • ANN (Approximate Nearest Neighbor) Search mechanics
  • Combinatorial Multi-Armed Bandits (CMAB) for cache eviction strategies

02 Models To Compile

  • Embedder: Deploy all-MiniLM-L6-v2 or a similar lightweight encoder
  • Semantic Judge: Fine-tune a 1B-parameter model exclusively for binary context equivalence classification

03 Data To Collect

  • Paraphrase datasets (e.g., Quora Question Pairs) to train the Semantic Judge to detect equivalent context
  • Internal workflow queries to test cache hit ratios locally
Phase 03

Intelligent Routing Matrix

01 Things To Learn

  • LLM Cost Evaluation and Context Window capacities
  • Token estimation algorithms (e.g., tiktoken wrapper implementation)
  • Dynamic load balancing & Rate-limit (429) backoffs

02 Things To Build

  • Complexity Estimator (Analyzes prompt length, presence of tools/schemas)
  • Traffic Director (Switches endpoint based on analysis: e.g. Haiku vs Opus)
  • Adaptive load balancing algorithms

03 Data To Collect

  • Live pricing and Rate-limit sheets for leading models
  • Testing matrices comparing model response accuracy vs token tier
Phase 04

Agentic Chunking (Anti-Hallucination)

01 Things To Learn

  • Propositional Decomposition (Meaning-aware dataset segmentation)
  • RAG (Retrieval-Augmented Generation) logical failure modes
  • Strict Structured Outputs (JSON Schema validation) in LLM calls

02 Things To Build

  • Chunker Pipeline: Replace literal token-splitting with a pre-processing LLM pass to isolate facts
  • Deterministic Engine: Split processing into "Evidence Gathering" and "Final Synthesis" to constrain LLM freedom

03 Data To Collect

  • Highly complex, noisy documents (PDFs, multi-page specs) to baseline Hallucination rates
  • "Needle in a Haystack" benchmark structures measuring retrieval precision
Phase 05

Testing & Integration

01 Things To Learn

  • Model Context Protocol (MCP) integrations
  • VS Code Extension APIs (LanguageModelChatProvider endpoint mapping)

02 Things To Build

  • Local Metrics Dashboard mapping Cost Saved vs Token Spend
  • Integration test suites orchestrating via Cursor & Windsurf

03 Final Analysis

  • Compare latency (TTFT) and token efficiency empirically against an un-proxied API connection

Sway ↗ Built for efficiency · Designed for impact
